## M1 计时器上线

**T1.1 口令门**

- [ ] 未登录访问任何页面 → 跳转 /login
- [ ] 错误口令提示错误；正确口令进入首页且 30 天内免登（cookie 验证）

**T1.2 方案选择首页**

- [ ] 按场景分组显示 19 方案，常用可置顶
- [ ] 每方案显示已采样本数

**T1.3~T1.5 计时器向导**

- [ ] 选方案 → 创建 session → 进入向导，主按钮按状态机流转（出发→到站→上车→沿途→下车→到达）
- [ ] 等车阶段快捷条可点击且可重复更新（连续点 3、1 → wait_snapshots 两条记录）
- [ ] missed 一键：missed_count+1，状态回到等待，快捷条仍可用，流程不中断
- [ ] 沿途站可跳过（直达下车），也可连续打多个 station_arrive
- [ ] 手机上刷新页面 → 恢复到最后状态，不丢数据
- [ ] 所有按钮手机单手可点（≥48px），页面无横向滚动

**T1.6 车辆抓取**

- [ ] wait_start 打点后 session.vehicle_plate 有值（DSAT 正常时）
- [ ] DSAT 不可达时打点仍正常返回，vehicle 字段为空，dsat_call_logs 记录失败
- [ ] 打点响应 < 500ms（抓取异步，不阻塞）

**T1.7 结束页**

- [ ] 拥挤度四选一提交成功，total_minutes 自动计算正确（与打点间隔一致）
- [ ] weekday/time_bucket 正确（GMT+8）

**T1.8 部署上线**

- [ ] *.vercel.app 手机浏览器访问，口令门生效（HTTPS 正常）
- [ ] 完整走通一次真实通勤：选方案→全流程打点→结束提交，云端库可查到该 session 及全部 events
- [ ] 页面底部标注「数据来源：澳门交通事务局」

**T1.9 PWA**

- [ ] iOS/Android 浏览器「添加到主屏幕」后图标正常、全屏打开
