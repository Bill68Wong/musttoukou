## 一、导航模型改造（候选寻路层强化）

### 1.1 候选数控制（`src/lib/nav/graph-search.ts`）
- **链级变体限额** `perChainLimit=12`：同一条「链」（乘车段线路序列）最多保留 12 个「上车站×换乘点×下车站」变体——修「同线路链多变体吃光全局名额、挤掉其它链与 2 换乘」（研究报告 §4.6 首推项）。
- **1 换乘阶段预算** `stage1Share=0.6`：到点即收手，给 2 换乘留名额。
- **变体优度排序**：同一链优先产生「近上车站 × 近下车站」组合（SRC/DST 距离序），被限额砍掉的是较差变体。

### 1.2 融合排序改革（`merge-sources.ts` + `nav-service.ts`，产品口径 2026-09-19）
- **废除「只许赢」闸门**：本地候选不再要求「严格快于高德最优」才保留（开关 `requireFasterThanAmapBest` 保留、默认关）。
- **废除本地数量配额**：不再限「最多 2 张」，两来源全部进统一 `T_ours` 排优。
- **本地枚举请求期现场跑**：不再依赖离线 `shadow_diff_report` 表（其只覆盖历史 OD），`maxCandidates=240`，任意 OD 均可现场枚举。
- 保留质量闸门：站序可解 / 与高德去重 / `suspect` 剔除 / 覆盖率 ≥0.5。

### 1.3 多策略按需补查（`transit.ts` + `nav-service.ts`）
- 默认只查 `strategy=0`；当**可用候选 <3** 时并行补查 `s=7/8`，按方案指纹（线路名+上下车站名）去重合并（`s=0` 优先）。
- 缓存键加策略维度（`<odKey>|s<strategy>`）防串缓存；单策略失败静默忽略，不拖垮主流程。

### 1.4 站名异体字折叠（`src/lib/shared/normalize.ts`）
- 新增 `VARIANT_PAIRS`（`栢柏`/`峯峰`/`恆恒`/`羣群`/`滙汇`/`邨村` 6 对），`normalizeName` 与 `normalizeQuery` 同步折叠。
- 修复实测案例：高德「荷兰园**栢**蕙」vs 库内「荷蘭園**柏**蕙」桥接失败（研究报告 b3 样本 14 条全部此因）；核验结论：**代码折叠即解，无需补数据行**。

## 二、首页地图 · 巴士站点标注

### 2.1 站点图层（`NavMap.tsx`）
- **显示策略**（产品口径）：拉远（`zoom < 16`）**不显示**；放大到阈值后显示**屏幕内**站点（`getBounds()` 视野裁剪）；移动/缩放过程**零请求**（本地裁剪）→ 交互不卡。
- 观测钩子（无副作用）：`data-nav-z`（实际 zoom）、`data-station-count`（渲染数），供自动化验收。
- 渲染：轻量 DOM 圆点（`.nav-map__station`），移出视野即 `map.remove()` 清理防泄漏。

### 2.2 站点信息卡（`StationCard.tsx`）
- 点击站点 → 卡片：站名（繁体）+ **该站全部线路实时报站**（线路标签 + 往向 + 还有 N 站/约 M 分；单线失败标「暂无数据」）+ 「设为起点 / 设为目的地」。
- 报站口径复用 **`fetchStationLive`**（与 `/nav/detail` 详情页「本站台其他线路」同一实现），无第三套口径。

### 2.3 新接口与安全
- `GET /api/stations`：全量巴士站（主码去重；库内 **WGS84 → 服务端转 GCJ-02**；`s-maxage=3600`）。
- `GET /api/station/eta?code=<主码>`：站点报站（并发≤6、整体超时 8s、内存缓存 20s 防连点）。
- `middleware` 白名单 **+2**（仅这两个接口，其余路径保护策略不变）。
- `PoiSearchBox` 增加「外部设点 → 输入框同步」（含 label 守卫，避免覆盖用户输入）——修复地图选点后搜索框不回显的问题。

## 五、已知边界与观察项

1. **DSAT 调用量**：单次 `/nav` ≈ **49 次** DSAT 请求（本地 240 候选全量喂实时；旧版 8~16 次级）。当前用户量下可接受；若未来并发上来，可先限制进入 `fetchLive` 的本地候选数。（QA 补充：线上 `liveMs` 有放大可能，列观察项。）
2. **深夜 OD 时间**：23:20「關閘→澳科大」本地卡片 136 分起——QA 独立核验为**真实推算**（中段长绕行 + 快线收车被剔）；23:38 复测最优链 **64.9 分**（5→71S，L1 实测为主），与真实夜间出行吻合。
3. **`loadStatics` 缓存警告**：本地 `next start` 日志出现 `items over 2MB can not be cached`（≈5.9MB），为既有现象（非本版引入）；本机实测 `staticMs=0`（进程内复用有效），观察项。
4. **站点图层阈值** `STATION_MIN_ZOOM=16` / 变体限额 `perChainLimit=12` / 阶段预算 `stage1Share=0.6` / 补查阈值 `MULTI_STRATEGY_WHEN_BELOW=3`——均为显眼常量，可按体感微调。
5. **站码映射存量问题**：全量 560 行审计 → `#793` 已修（§3.1）；另有多处「名词性差异」行待人工复核（`.verify/audit-amap-map.out.txt`）+ 简繁表缺字（贾/鴉/華…）待补——列入下轮。
6. **QA 遗留（非阻断）**：P2-2 多策略 0 增益监控 · P2-3 深夜超长绕行卡降权 · P3 同站重设边界 · 候选枚举性能上限（超大范围场景）。
