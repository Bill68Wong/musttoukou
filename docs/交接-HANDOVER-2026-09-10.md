## 二、系统概览

- **技术栈**：Next.js 全栈 + PostgreSQL；生产 Vercel + Supabase（真实主库），本地 PG=影子库
- **数据源**：DSAT 官方接口（澳门交通事务局，站序/车辆位置）+ motransportinfo（轻轨时刻表）
- **核心功能**：
  1. **通勤计时器**（`/` 首页 → `/routes` 选方案 → `/timer/[id]`）：全程打点（出发/等车/上车/逐站/换乘/口岸），产出行程样本
  2. **自由记站**（`/free`）：独立数据采集，实测任意两站间时长（全澳 92 巴士 + 3 轻轨），不入通勤统计
  3. **统计/记录**（`/stats` `/records`）：真实样本（deleted_at IS NULL 且 is_test=false）
- **关键表**：commute_plans / plan_legs（方案，route_meta 支持同台多线合并卡）· timer_sessions /
  timer_events（行程）· free_rides / free_ride_events（自由记站）· bus_snapshots（车牌抓拍）·
  lrt_timetables / stations / routes / route_stations

## 三、协作惯例（发版即交付）

1. **改动 → 验证 → 发布**：`npx tsc --noEmit` + `npm run build`（确认 **exit=0**）→ bump 版本 →
   annotated tag → `git push origin main --tags` → `git ls-remote` 复核
2. **本地构建前缀**：`CODEBUDDY_SAFE_DELETE_BULK_THRESHOLD=999999`（否则清 .next 触发宿主守卫假红）
3. **产线数据变更**：写 `db/migrate-vXXX.ts`（幂等），分别 `-- local` 与 `-- cloud` 执行
4. **看板同步**：完成项 → issue 关闭（自动 Done）；新需求 → `node scripts/gh-project.mjs backlog "标题"`
5. **检查清单**：改 UI 必无头浏览器真跑；改 client 组件禁 import 含 pg 模块；新增常量引用下方 const 要惰性化
6. **称谓边界**：对话中「用户」；代码/文件/文档/GitHub 一律中性称谓
