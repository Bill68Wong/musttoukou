> **关于 3.5「不得存储服务数据」**：
> 我们存的是一个**派生数值**（两点间的步行米数），不是高德的地图瓦片/图片/POI 数据集。
> 条款的立法意图在于防止「脱离服务单独使用其数据资产」。
> **保守做法（已采纳）**：
> 1. 只存**必要的派生数值**，不存路径 polyline、不存地图图片
> 2. 记录**来源与取得日期**（`fetched_at` 列已实现）
> 3. 若日后需大规模存储，**提工单向官方确认**（3.5 原文即指引「可提交工单咨询」）

### 8.1 开发者的四项承诺（政策 一 · 1）

平台**要求开发者承诺**：

> ⚠️ 违反导致高德遭受投诉、调查、处罚的，**开发者需全额赔偿**。

### 8.2 ★★ 关键区分：我们用的是「Web 服务」，**不是 SDK**

隐私政策通篇在讲 SDK（定位/地图/导航/搜索/猎鹰/司乘同显…），
但**本项目没有集成任何高德 SDK** —— 我们走的是**服务端 Web 服务 API** ✓

| | SDK 方式 | **本项目（Web 服务）** |
|---|---|---|
| 谁发起请求 | **用户设备** | ✅ **我们的服务器** |
| 收集设备信息（OAID/IDFA/传感器/经纬度…） | 是 | ✅ **完全不会** |
| 需要用户授予定位权限 | 是 | ✅ **不需要**（我们不用用户定位） |
| 设备与高德是否直接通信 | 是 | ✅ **不通信**（只与我们的服务器通信） |
| 隐私披露负担 | 重 | **较轻，但仍须披露** |

**⇒ 我们传给高德的只有「地点与巴士站点的固定坐标」——那是项目数据，不是用户个人信息 ✓**

### 8.3 ★ 我们的披露文案（建议直接用）

在 `/about` 页新增一节「第三方服务与隐私」：

> **高德地图服务说明**
>
> 本应用使用**高德地图开放平台**的「**Web 服务 API（路径规划）**」，
> 用于估算您从出发地/目的地步行到车站所需的时间。
>
> - **服务提供方**：高德软件有限公司
> - **使用的具体产品**：路径规划 API（步行）
> - **使用目的**：计算两点间的步行路径距离，进而估算步行时间
> - **涉及的信息**：若干**固定地点与巴士站点的坐标**（属本项目的公开数据，**不含您的个人信息**）
> - **调用方式**：由本应用的**服务器**发起，**您的设备不会与高德服务器直接通信**，
>   也不涉及读取您的定位、设备标识或任何个人信息
>
> 高德对相关信息的处理规则详见
> [《高德地图开放平台隐私权政策》](https://lbs.amap.com/pages/privacy/)
