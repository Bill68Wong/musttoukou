## 1. 首屏 HTML 仅骨架，数据由 RSC flight 载荷携带（SSR 流式）

**现象**：`/nav`、`/nav/detail` 用 `<Suspense>` 包住异步结果区。抓取首屏 HTML 时，
地图/卡片区只有骨架；**卡片与站条数据以 `self.__next_f.push([...])`（React Server Components
flight payload）下发**，由客户端 React 渲染。

**为何接受**：
- 本应用是 **PWA**，使用者必有 JS ⇒ 功能完整可用；
- 「导航工具」不依赖搜索引擎的 SEO（用户不会先搜「澳门路线」再进来用）；
- 去掉 `<Suspense>` 可换回纯 HTML SSR，但会**牺牲流式感知性能**（骨架先出的体验），
  T04 的 §11 感知性能目标优先。

**影响与应对**：无 JS / 爬虫场景下卡片不呈现（骨架可见，功能入口与页壳在 HTML 里）。
**QA 需用真浏览器复核**渲染链路正常。

接口保持 `loadAMap(jsKey, plugins) → Promise<AMap>`，**将来放开环境后一处可换回官方 loader**。
