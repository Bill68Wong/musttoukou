## 三、已识别的**系统性规律**（重要）

```
直线距离 < 200 米  →  结果全部不可靠 ✗
直线距离 ≥ 200 米  →  全部正常 ✓  （分界线极干净）
```

**成因推测**：起点若是**建筑内部**的 POI（如「澳科大 R 座」），
高德吸附到最近道路后，可能规划出「先绕出校园、再绕到站点」的路线 ✗

**佐证**：`T417` / `T429` / `LRT-MUST` 三个站彼此相距仅 **22~41 米**，
但 `澳科大 R 座` 走到它们的距离是 **447 / 447 / 776 米** —— 差 329 米 ✗ 不合理
