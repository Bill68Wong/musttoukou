## ④ ★ 结论：什么有数据、什么没有

### ✅ 有数据的
| 数据 | 覆盖 | 用途 |
|---|---|---|
| **站间行车时长**（线上） | 105 个站对 / 13 条线 · 696 样本 | 线上唯一的车程数据源 |
| **站间行车时长**（离线） | 875 个站对 · **60313** 样本 | ★ **尚未入库**，是线上的潜力储备 |
| 站点坐标 | 610/613 站 | 算距离 |
| 地点坐标 | 6 个（家/学校三座/两口岸） | 起终点 |
| 步行距离 | 37 组（地点↔站点） | 步行段 |
| 换乘步行 | 2 组（轻轨换乘） | 轻轨换乘 |

### ❌ 没有数据的（关键）
1. **任意 POI ↔ 站点 的步行时间** ✗
   - 现在只有 **6 个地点**（家/三个座区/两口岸）到站的步行距离
   - 全澳导航意味着**任意地址**都要算步行 → **必须靠高德现算**（我们没有、也不可能有）
2. **未被采集覆盖的站对** ✗
   - 线上 105 个站对 vs 理论约 2660 个 ⇒ 缺口很大
   - 但这些**可以通过继续入库离线数据来补** ✓（不是永久缺口）
3. **巴士线路本身的静态信息**（首末班、班距、票价）✗
   - 我们只做实时报站，没有运营时刻表 ✗
4. **任意 POI 的坐标/名称** ✗ → 必须靠高德 POI 搜索

### ★★ 所以要区分两类缺口
```
【可补的缺口】站间行车时长 —— 离线已有几万段，继续入库就能补 ✓
【不可补的缺口】任意 POI 的坐标与「POI↔站点」的步行路径
            —— 我们不可能为全澳门每个地址都实地测量 ✗
            ⇒ 这类必须用高德现算，我们只负责「车程」那一段 ✓
```
