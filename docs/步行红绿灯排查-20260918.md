## ① 高德步行 API 字段实测（最直接的答案）

**样本**：石排灣馬路/擎天匯 → 安順大廈（主人确认此段**有红绿灯**）

**试过的参数组合**（全部返回相同结构）：

| # | `show_fields` | path 顶层键 | steps[0] 的键 |
|---|---|---|---|
| ① | （不传） | distance, cost, steps | instruction, orientation, road_name, step_distance |
| ② | `cost` | 同 | 同 + `cost` |
| ③ | `steps` | 同 | 同 |
| ④ | `cost,steps` | 同 | 同 + `cost` |
| ⑤ | **`all`（全量）** | 同 | 同 |
| ⑥ | v3 老接口 | 同 | 同 |

**完整响应的全部键（递归，共 16 个）**：

```
count / info / infocode / status
route.origin / route.destination / route.paths
route.paths[].distance
route.paths[].cost.duration
route.paths[].steps[].instruction
route.paths[].steps[].orientation
route.paths[].steps[].road_name
route.paths[].steps[].step_distance
```

**🔍 键名里含 `light` / `signal` / `traffic` / `cross` / `intersect` 的：0 个** ✗

**一个 step 的完整内容**：

```json
{
  "instruction": "沿石排湾马路向东北步行136米右转",
  "orientation": "东北",
  "road_name": "石排湾马路",
  "step_distance": "136"
}
```

⇒ ★ **高德步行路径规划 API 完全不提供红绿灯信息** ✗

> ℹ️ 高德 App 确有「红绿灯倒计时」功能，但那是：
> ① **驾车**场景 ② **App 端本地能力** ③ 数据来自与交管部门的合作 ——
> **三者都不适用于 Web 服务 API** ✗
