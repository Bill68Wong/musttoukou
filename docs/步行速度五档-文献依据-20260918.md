## 二、文献依据

### 2.1 ★★ 正常（舒适）步速 —— 金标准 meta 分析

**Bohannon & Andrews (2011)**，*Normal walking speed: a descriptive meta-analysis*
- 发表于 *Physiotherapy* 97(3):182-189 · PMID **21820535**
- **41 项研究 · 23,111 名**健康社区居住成人
- 测量方式：自选舒适速度，行走 **3~30 米**
- 结果：男性 **4 0-49 岁最快 143.4 cm/s**；女性 80-99 岁最慢 94.3 cm/s

**按年龄/性别（m/s）**：

| 年龄 | 男性 | 女性 |
|---|---|---|
| 20–29 | **1.36** | 1.34 |
| 30–39 | 1.43 | 1.34 |
| 40–49 | **1.43** | 1.39 |
| 50–59 | 1.43 | 1.31 |
| 60–69 | 1.34 | 1.24 |
| 70–79 | 1.26 | 1.13 |
| 80–99 | 0.97 | 0.94 |

**更新版**：**Andrews, Vallabhajosula, Boise & Bohannon (2022)**，*Normal gait speed varies by age and sex but not by geographical region: a systematic review*
- 发表于 *Journal of Physiotherapy* · PMID **36528509**
- **51,248 名**健康成人（样本量翻倍）
- 加权平均步速范围：**97 cm/s（80+ 女性）~ 140 cm/s（40-49 男性）**
- ★ 结论：**步速不因地理区域而异** ⇒ 亚洲/澳门人群可直接套用 ✓

### 2.2 舒适 vs 最大步速（「走」的速度上限）

**Bohannon (1997)**，230 名健康志愿者（20–79 岁）：

| 年龄 | 舒适（男/女） | **最大（男/女）** |
|---|---|---|
| 20–29 | 1.39 / 1.40 | **2.53 / 2.27** |
| 30–39 | 1.46 / 1.38 | 2.43 / 2.14 |
| 40–49 | 1.46 / 1.38 | 2.35 / 2.12 |
| 50–59 | 1.39 / 1.40 | 2.18 / 2.01 |

⇒ ★ **「走」的最大速度约 2.1~2.5 m/s** —— 超过就是「跑」了 ✓
⇒ 本文档把它作为第 2 档（小跑）的下界参照 ✓

### 2.3 快走 / 慢走

- **快走（brisk walking）**：约 **1.56 m/s**（3.5 mph）起，健身步速可达 **1.79 m/s**（4.0 mph）
- **慢走**：约 **1.0 m/s** 左右（低于舒适步速 30%）
- 步行↔跑步的转换速度约 **2.0 m/s**（常见文献值）

### 2.4 跑步侧（第 1、2 档）

| 层级 | 速度 |
|---|---|
| **未训练成人慢跑** | **2.2~2.7 m/s**（5~6 mph） |
| 休闲跑者 | 3.1~4.0 m/s（7~9 mph） |
| **未训练成人最大冲刺** | **4.5~5.8 m/s**（10~13 mph） |
| 有训练冲刺者 | 6.7~8.0 m/s（15~18 mph） |
| 顶级运动员 | 10~12 m/s |

⚠️ 注意：未训练的普通人**最大冲刺只能维持 1~3 秒** ✓ 但恰好符合「赶车冲刺几十米」的场景 ✓

### 2.6 ★ 背包负重（学生场景必考虑）

| 负重（占体重） | 速度降低 | 说明 |
|---|---|---|
| **10% 以下** | **1~3%** | 几乎不影响短距离，长距离会增加疲劳 |
| 20% | 10~15% | 跑步时步伐明显沉重 |
| 30% | 25% 以上 | 「战斗负重」临界点，爆发力大幅下降 |
| 50% 以上 | 50% 以上 | 难以跑动，多半只能快走 |

- 生理机制：负重 20kg 时行走能耗增加 **30~50%**；步距变短、触地时间增加
- 学生书包典型 **5~10 kg**，体重按 60~70 kg 计 ⇒ 占 **8~15%** ⇒ 约降 **5%**

#### ★★ 施加原则（关键，避免重复扣减）

```
档 1、2  ← 基于文献（受控实验多为无负重）⇒ **需要**加背包修正（-5%）
档 3、4、5 ← 基于本项目**实测**，而实测时主人本就背着书包
              ⇒ 背包影响**已包含在内**，不可重复扣 ✗
```

⚠️ 这是最容易搞错的地方：**不能因为「背包会降速」就把五档统统往下调** ——
基准档（3）的数值来自真实行走，那道修正已经在数据里了 ✓

### 2.7 短距离冲刺的「加速损耗」

峰值速度**不可直接用于赶车场景**：

| 项 | 说明 |
|---|---|
| 峰值速度可维持 | 仅 **1~3 秒** |
| 达到峰值所需距离 | **10~15 米**（约 2~3 秒） |
| 赶车实际跑动距离 | **20~50 米**（中位约 30~40 米） |
| ⇒ 平均速度 | ≈ 峰值的 **75~80%** |

```
未训练成人峰值 4.5~5.8 m/s
 ⇒ 20~50m 平均 ≈ 3.5~4.4 m/s
 ⇒ 计背包（-5%）≈ 3.3~4.2 m/s
 ⇒ 取保守侧 **3.6 m/s** ✓
```

## 四、★ 一个重要的口径说明（避免双重计数）

Bohannon 的测量是「**3~30 米，从『开始』口令起走**」——
论文自己明确警示：

> The data presented herein may not be useful as a standard of normal if gait is measured over
> **short distances from the command 'go'** or if a **turn is involved**.

⇒ **短距离测量会含起步加速，测得的速度偏低** ✓

而本项目 `catch-up.ts` 的计算式是：

```
requiredSec(baseMin, tier) = OVERHEAD_SEC + (baseMin×60 − OVERHEAD_SEC) × SPEED_RATIO[tier]
```

其中 `OVERHEAD_SEC = 15` 秒**已经把起步/反应/等灯的固定开销单独扣除** ✓

**⇒ 因此 `SPEED_RATIO` 对应的应是「纯行走的稳态速度」，不含起步** ✓

**实践影响**：稳态速度略高于 3~30m 的平均速度（约高 5~10%）✓
- 若把文献的 1.43 直接当稳态用 → 略保守（步行时间偏长一点点）✓
- 考虑本项目「**能否赶上的判定一律用下限**」（往短了算）的既有原则 ⇒ **保守是对的** ✓

⇒ **维持 1.4 m/s 作为稳态基准，不再上调** ✓

## 七、★ 耐力问题：档 1 会随距离衰减（2026-09-18 · 主人提出）

### 7.1 主人原话

> 「另外思考一下人的耐力，会不会随路程的增加，12 的速度会下降」

### 7.2 生理学依据：能量系统的时间轴

| 持续时间 | 主导供能系统 | 说明 |
|---|---|---|
| 0~3 秒 | **磷酸原（ATP-PCr）** | 占约 65% |
| 3~6 秒 | 磷酸原仍主导 | 但已降至一半 |
| **6~10 秒** | ★ **PCr 耗竭** | **「撞墙」点** |
| 15~30 秒 | 糖酵解上升 | 乳酸开始堆积 |
| 30 秒~2 分 | 糖酵解主导 | |
| 3 分以上 | 氧化系统主导 | |

**关键引用**：
> "PCr stores are depleted within approximately **8-10 seconds** of maximal effort"
> "a 100m sprinter hits a 'wall' somewhere after the first **6-8 seconds**"
> "By about **6 seconds**, that system is already providing only **half** your energy"

⇒ **全力冲刺的可持续距离 ≈ 3.6 m/s × 8 秒 ≈ 29 米** ✓（取整 **30 米**）

### 7.3 ★ 问题量化：现有公式高估多少

现有算式（`catch-up.ts#requiredSec`）是**线性**的 —— 一个 `SPEED_RATIO` 乘到底：

```
requiredSec(baseMin, tier) = OVERHEAD + (baseMin×60 − OVERHEAD) × SPEED_RATIO[tier]
```

用档 1（ratio 0.39）试算不同距离：

| 距离 | 现在算出的耗时 | 隐含平均速度 | 生理上可行？ |
|---:|---:|---:|---|
| 30 m | 20.2 s | 1.49 m/s | ✅（但未用满冲刺能力） |
| 100 m | **37.0 s** | **2.70 m/s** | 🟡 勉强（需维持 2.7 m/s 跑 37 秒 ⇒ 超出无氧能力） |
| 300 m | **92.7 s** | **3.24 m/s** | 🔴 **不可能** —— 3.24 m/s 只能维持 8 秒 |
| 1000 m | 293.6 s | 3.41 m/s | 🔴 **荒谬** |

⇒ ★ **距离越长，高估越严重** ✗（300 米时高估约 **50%**）

### 7.4 档 2 不需要修正 ✓

2.0 m/s 对年轻人属**中低强度有氧**，可维持数十分钟 ✓
（参照：4~5 分钟的中高强度跑仍可 80% 有氧供能）
⇒ 「小跑」在赶车场景的距离量级（几十~几百米）内**几乎不衰减** ✓

### 7.5 ★ 修正模型（第二版 · 只有两段）

> **第一版我写错了**：曾给出「冲刺 30m → 小跑 370m → 走路」的三段模型，
> 结果 1000 米算出 621.9 秒，**比档 2（纯小跑 1000m = 500s）还慢** ✗
> ——「冲刺+小跑」不可能比「纯小跑」慢，逻辑矛盾。
> ★ 正确的衔接是：**档 1 = 冲刺 30 米 + 剩余全部按档 2 的小跑**（两段，不是三段）

```
档 1 = 冲刺 30 m @3.6 m/s  +  剩余全部小跑 @2.0 m/s
档 2 = 全程小跑 @2.0 m/s（本身有氧强度，不衰减）
```

### 7.7 ★★ 为什么档 2 不修正（重要的判断原则）

我一度想给档 2 也设一个「400 米上限」，依据是「用户不会小跑 1 公里」——
**那又是在替用户做行为假设** ✗，而这正是主人刚指出的问题 ✓

必须区分两类约束：

| 类型 | 档 | 说明 | 要修吗 |
|---|---|---|---|
| **生理硬约束** | **档 1** | PCr 8 秒耗竭 ⇒ **3.6 m/s 物理上不可能**维持 100m 以上 | ✅ **必须修**（不修就是算错） |
| **行为偏好** | 档 2 | 2.0 m/s 是有氧强度，**真的能跑 1 公里** | ❌ **不修**（模型没算错） |

> ★ **原则**：只要是**生理上可能**的事，就把真实数值交给用户，由他自己判断要不要；
> 系统只负责**不给出物理上做不到的建议** ✓

### 7.8 影响表（按 `catch-up.ts` 现有结构）

现有结构是**刻意设计**的（注释写明「让短距离各档绝对差自动收敛」）：
```
requiredSec = OVERHEAD + (baseSec − OVERHEAD) × SPEED_RATIO[tier]
```
⇒ 修正方式**不是改结构**，而是让 **ratio 成为距离的函数**：
```
effRatio₁(d) = 1.4 ÷ (d ÷ tier1Sec(d))
```

⇒ **≤30 米完全不变**（最常见场景：校门口跑到站台）✓
⇒ 长距离修正巨大 —— 原模型等于假设「3.6 m/s 跑满 1 公里」✗
