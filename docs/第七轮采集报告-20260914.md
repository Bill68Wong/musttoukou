### 3.2 ★★ 分解验证（内部自洽性）

```
时段效应 : am_peak ÷ night = 1 / 0.82 = 1.22
周几效应 : night(周一) ÷ night(周日)      = 1.06
预测      : 1.22 × 1.06 = 1.293
实测      : am_peak(周一) ÷ night(周日)   = 1.31     → 偏差 1.2% ✓
```

```
时段效应 : day ÷ night = 1 / 0.89 = 1.124
周几效应 :                          1.06
预测      : 1.124 × 1.06 = 1.191
实测      : day(周一) ÷ night(周日) = 1.22          → 偏差 2.4% ✓
```

```
交叉校验 : day ÷ am_peak = (day/night) / (am_peak/night) = 1.124 / 1.220 = 0.921
实测      : 0.94                                    → 偏差 2.0% ✓
```

→ ★★★ **三条独立路径一致 → 可分解性成立**：
**`am_peak ÷ night ≈ 1.31` 中，时段贡献 22%，周几只贡献 6%。**
