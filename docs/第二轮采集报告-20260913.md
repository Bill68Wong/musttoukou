## 三、5 秒 vs 10 秒的收益核算（★ 与直觉不同）

| 指标 | 变化 | 解读 |
|---|---|---|
| 请求数 | **×1.96** | 翻倍成本 |
| 离开段样本 | ×1.08（2998→3251） | **几乎没多**：每段样本量早已饱和 |
| 状态缺口 | **−56%（59→26）** | 采样密 → 漏检大减 |
| 站序不邻接丢弃 | −33%（246→164） | 同上 |
| 双口径差 σ | −17%（33.0→27.3 s） | 量化误差 ↓ |
| 量化台阶 | ±4.1 s → **±2.0 s** | `σ_量化 = S/√12 × √2`，S 从 10 s 降到 5 s |

**结论：5 秒的收益主要是「准」而不是「多」。** 提速真正买到的是**更少漏检 + 更小量化误差**，
而不是更多段样本 —— 这一点对后续决定「要不要再加密」很关键（服务端粒度 ≈5 s，再密无收益）。

## 五、★★ 新发现：站外长时间停留会造出假长区间

### 5.1 现象
```
2A路 dir=0 AA2851  M144(idx14) → M76(idx15)  离开 11.90 分
  同共享键 M144|M76|0|night 的其余样本：min 2.0 / p50 2.83 / 其余全在 2~5.14 分
  → 一条离群值把该键均值从 2.83 抬到 3.40（+20%）
```

### 5.2 轨迹（带 `idx` 的压缩状态）
```
s1@M153  idx=10  22:37:18~22:37:43  ×6
s0@M153  idx=10  22:37:48~22:37:58  ×3
s1@M144  idx=14  22:38:03~22:38:13  ×3
s0@M144  idx=14  22:38:18~22:49:42  ×138   ← 挂了 11.4 分钟
s1@M76   idx=15  22:49:47~22:50:07  ×5
```
前一段 `M153(idx10) → M144(idx14)` 只花 15 秒（idx 跳 11~13，快速行驶），
说明车到 M144 后**并没有在路上跑 11 分钟**，而是停着（休息 / 待發）。

### 5.3 为什么现有过滤全部失效
| 过滤 | 为什么拦不住 |
|---|---|
| ① 严格相邻（`idx` 差 = 1） | 14 → 15，**严格 +1** |
| ② 无状态缺口（s1→s1 跨站） | 中途有 s0 帧，**不是缺口** |
| ③ 时长合理（0.1~20 分） | 11.9 分**在范围内** |
| 附加：`idx` 一致护栏（v0.27.1） | s0 与 s1 的 idx 都是 14，**一致** |
| 附加：`s0` 持续时长 | ❌ 判不出来 —— **真实跨海段同样长时间挂 s0**（`s0@T317 idx=7` 挂 108 帧 ≈ 8.9 分后到 `M247`，那是真的） |

→ **唯一可靠判据 = 同一邻接站对上「其余样本是否一致」**（跨线路、跨车，用共享键聚合）。

### 5.4 规模（不值得为此牺牲真实长区间）
第二轮 3251 条离开样本中：**>8 分仅 12 条 · >10 分仅 4 条（<0.4%）**。
而真实跨海段恰是 ETA 方差的主来源（`M9→T316` 全组 9.58~12.74 分、`T317→M247` 9.33~9.83 分）
→ **绝不能再用「丢 >5 分钟」这类阈值清洗**。

## 六、★ 修法：同键一致性护栏（v0.27.2）

### 6.1 规则
```
阈值 thr = max(p50 × 3, p50 + 2 分)      // 两个条件都要过（取严）
仅当同一共享键样本数 n ≥ 5 时启用
样本 > thr → 标记为可疑：从均值/双口径/真值对照中剔除，但原值保留在 derived.json 可回溯
参数可覆盖：--outlier-mult / --outlier-floor / --outlier-min-n
```
落在**聚合层**（不是解析层）：因为单看一辆车的轨迹无法区分「真长区间」与「站外停留」。

### 6.2 为什么不会误伤真实长区间
真实跨海段**同键多样本且彼此一致** → `p50` 本身就大 → 阈值随之上抬：

| 键 | 组内样本 | 阈值 | 命中 |
|---|---|---|---|
| `M9｜T316` | 9.58~12.74 分（p50 12.0） | 36 分 | **0** ✅ |
| `T317｜M247` | 9.33~9.83 分（p50 9.76） | 29.3 分 | **0** ✅ |
| `M144｜M76` | p50 2.83，孤立 11.90 | 8.48 分 | **1** ✅ 精确命中 |

### 6.3 第二轮复算验证（重跑派生，只读）
- 命中：**离开口径 1 条 / 到达口径 3 条**（3251 / 3506 样本）→ 零误伤
- `M144|M76|0|night`：均值 **3.40 → 2.83**（回落至 p50 水平）、max 11.9 → 4.42
- 真值对照最差清单里 `2A路 M144→M76 +8.30 分` **消失**；MAD 44 → **42 秒**
- 双口径 σ 27.4 → 27.3 秒
- 到达口径另揪出两条同型样本：`2路 M203|M3` 11.58 分（同键 p50 1.92）、`26路 C654|C653` 4.37 分（p50 1.42）

### 6.4 已知局限
- **同键样本 < 5 时护栏不启用**（样本太少判不出一致性）→ 报告第六节明确提示，
  这类键的极端值仍需人工核查（如双口径差 `9A|M23|M4` −260 秒，n=1）。
- 阈值是**统计判据**，对「真实但罕见的路况事件」理论上有误剔风险 → 因此**只剔均值、不删原始**，
  报告与 json 都留全量清单，随时可回溯复核。
