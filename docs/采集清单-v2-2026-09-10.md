# 采集清单 v2（2026-09-10）

> 目标：把「自由记站 / 通勤计时」的站间段样本补到**每段 ≥2 次**，为「自动选线」建模打底。
> 自查命令：`npm run db:coverage -- cloud`（只读，随时可跑；输出「哪段还缺」）

---

## 一、口径（v0.22.0 定稿）

| 项 | 口径 |
|---|---|
| 段 | 站序中**相邻两站**为一段；段时长 = `t(下一站) − t(上一站)`，差里只含**起点站**停站时间 |
| 可用端点 | `station_arrive`/`stop_arrive`（停靠）、`station_pass`/`stop_pass`（**甩站**，车经过站台，时刻真实可用）、`board`（上车）、`alight`（下车） |
| 不可用端点 | `station_skip`/`stop_skip`（**忘记打卡**补点，无真实到站时刻，仅推进 UI） |
| 分档 | `arrive_kind`：`stop`（起点停靠，含停站 → ETA 主用）/ `pass`（起点甩站 ≈ 纯行驶 → 反推停站耗时）/ `all`（合并） |
| 分层 | `weekday 0-6` × `time_bucket`（am_peak 7-10 / day 10-17 / pm_peak 17-20 / night）+ 兜底行（`weekday=-1, bucket=all`） |
| 规则 | 同站不同台（主码相同）= 站内停留/换乘，不计入段 |

**当前存量**（cloud，2026-09-10）：24 会话 + 1 自由记站行程 → **141 段样本**（timer 127 / free 14）· 头段 24 / 末段 25 · 档位 stop 124 / pass 17 · 写 **312 行** · 43 个区间已有 ≥2 次样本。
